# second-brain

Knowledge base of go-order-manager: notes, decisions, runbooks, postmortems and prompts. Root `CLAUDE.md` rules apply, including the public-repo golden rule.

## Vault structure (PARA)
`00_Inbox` loose ideas, `01_Projects` one note folder per stage, `02_Areas` Go, Microservices, Observability, `03_Resources` references, `04_Archive`, `06_Metadata/Templates`.

## Rules
- Notes in pt-BR, one file per concept, linked to each other.
- After each simulated incident, write a runbook and a postmortem.
